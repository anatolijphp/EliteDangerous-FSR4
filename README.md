# ED-FSR — FSR 4 / FSR 3.1 and Frame Generation for Elite Dangerous

A drop-in mod that replaces Elite Dangerous' built-in **AMD FSR 1** upscaler with **AMD FSR 4 (ML)** or **FSR 3.1**
temporal upscaling, and adds **AMD FSR Frame Generation**. The mod comes with an in-game settings panel styled to match
the game's HUD.

> Unofficial fan project. Not affiliated with or endorsed by Frontier Developments or AMD.
> It modifies rendering only, with no gameplay or memory changes. Use at your own risk.

## Features

- **FSR 4 (ML)** on RDNA 4 GPUs (Radeon RX 9000). **FSR 3.1** works on other GPUs. You can switch between them at
  runtime.
- **Temporal upscaling inputs generated by the mod.** Elite Dangerous has no TAA and no motion vectors. The mod adds
  sub-pixel camera jitter and rebuilds camera motion vectors from the depth buffer and the game's view-projection
  matrices.
- **FSR Frame Generation (FSR FG 4 on RDNA 4).** The mod presents through an AMD FidelityFX frame-generation swapchain
  (D3D12), bridged from the game's D3D11 renderer.
- **In-game overlay.** A hint appears at startup. **CTRL+F8** opens the settings panel, where you can change the
  upscaler, sharpness and frame generation, and use the advanced options and live status. Settings are saved to
  `edfsr.ini`.
- **Safe fallback.** If anything fails to initialise, the game's original FSR 1 path is used.

## Requirements

- Elite Dangerous (Horizons 4.0 / Odyssey client, DirectX 11), Windows 10/11.
- A GPU with DirectX 12 support. FSR 4 needs an AMD RDNA 4 GPU and a recent Adrenalin driver.
- In-game settings:
  - **Upscaling = FSR.** The game's *Supersampling* setting picks the render scale.
  - **Anti-aliasing = Off** (recommended).
  - **Borderless window mode**, if you use frame generation.

## Installation

1. Download the latest build from **Releases**, or the `ed-fsr` artifact of a CI run.
2. Copy the contents to `D:\ed-fsr\`. The mod currently loads its config and the FidelityFX DLLs from this folder:
   `D:\ed-fsr\edfsr.ini` and `D:\ed-fsr\bin\*.dll`.
3. Close the game. Run `install.ps1`, which copies `dinput8.dll` into the game folder. Pass `-GameDir <path>` if your
   game folder is not `D:\Epic Games\EliteDangerous\Products\elite-dangerous-odyssey-64`.
4. Start the game. The "ED-FSR" hint appears in the top-right corner. Press **CTRL+F8** to configure.

To uninstall, run `install.ps1 -Uninstall`, or delete `dinput8.dll` from the game folder.

## How it works

- **Loading.** `dinput8.dll` is a proxy for the system DirectInput DLL. It hooks D3D11 device creation and selected
  context methods: `CSSetShader`, the CS SRV/UAV setters, `OMSetRenderTargets` and `RSSetViewports`.
- **Replacing EASU.** The game's FSR 1 EASU compute shader is identified by a hash of its bytecode and swapped for a
  no-op. Before the following RCAS pass, the mod copies color, depth and motion vectors to textures shared with
  D3D12. It then runs `ffxDispatch` (AMD FidelityFX SDK 2.4) and writes the result back into the game's upscaled
  texture.
- **Jitter.** Jitter is applied as a sub-pixel viewport offset while the scene depth buffer is bound. Motion vectors
  come from depth plus the per-frame camera constant buffer.
- **Frame generation.** The game's swapchain is redirected to a hidden window. Every `Present` hands the frame to an
  FFX frame-interpolation proxy swapchain on the real window.
- **Overlay.** The settings overlay uses Dear ImGui.

## Building

The build uses the [llvm-mingw](https://github.com/mstorsjo/llvm-mingw) toolchain, the
[AMD FidelityFX SDK 2.4](https://github.com/GPUOpen-LibrariesAndSDKs/FidelityFX-SDK), [Dear ImGui 1.91.8](https://github.com/ocornut/imgui)
and `renderdoc_app.h`:

```sh
LLVM_MINGW=... FFX_SDK=... IMGUI_DIR=... RENDERDOC_INC=... sh build.sh   # -> build/dinput8.dll
```

GitHub Actions (`.github/workflows/build.yml`) downloads all dependencies and builds on every push. Tags `v*` produce
a release zip.
